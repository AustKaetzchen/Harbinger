Installing dependencies on local:
1. `conda activate sam_env`
2. `conda install -c conda-forge opencv numpy scipy matplotlib pillow spyder`
3. `conda install pytorch torchvision torchaudio pytorch-cuda=11.8 -c pytorch -c nvidia`
4. `conda install pytorch torchvision torchaudio cpuonly -c pytorch`
5. `pip install kornia`
6. `pip install romatch`
